We're excited to have you contribute to BountyPort! Whether you're a developer, designer, or community member, there are many ways to get involved.

## Contributing to BountyPort

- **Code Contributions**: If you're a developer, you can contribute to the smart contracts, indexer service, or web application.
- **Documentation**: If you're a writer, you can help improve our documentation by adding new guides or improving existing ones.
- **Testing**: If you're a tester, you can help identify and report bugs in our platform.
- **Community**: If you're a community member, you can help spread the word about BountyPort and provide feedback on our platform.

## Getting Started

1. **Fork the repository**: Create a fork of the BountyPort repository on GitHub.
2. **Clone the repository**: Clone your fork to your local machine.
3. **Create a branch**: Create a new branch for your contribution.
4. **Make changes**: Implement your contribution in your new branch.
5. **Run tests**: Ensure your changes pass all tests.
6. **Submit a pull request**: Create a pull request to the BountyPort repository on GitHub.

## Code Style

- **TypeScript**: Follow the [Google TypeScript Style Guide](https://google.github.io/styleguide/tsguide.html).
- **Solidity**: Follow the [Solidity Style Guide](https://docs.soliditylang.org/en/v0.8.20/style-guide.html).
- **React**: Follow the [React Style Guide](https://github.com/airbnb/javascript/tree/master/react).

## Reporting Issues

If you encounter any issues with BountyPort, please report them on our [GitHub issue tracker](https://github.com/bountyport/bountyport/issues).

Be sure to provide as much detail as possible, including:

- **Issue description**: A clear and concise description of the issue.
- **Steps to reproduce**: The steps you took to reproduce the issue.
- **Expected behavior**: What you expected to happen.
- **Actual behavior**: What actually happened.
- **System information**: Your operating system, browser, and Node.js version.
