## What is BountyPort?

BountyPort is an MVP-stage decentralized bounty platform designed to connect open-source maintainers with contributors through a trustless, transparent mechanism. 

Built on Ethereum (currently testing on local Foundry), it allows maintainers to post bounties, contributors to submit work, and rewards to be distributed automatically upon approval.
