BountyPort is currently in an **MVP** stage, focusing on the core bounty lifecycle. Here's our roadmap for future development:

## What's Intentionally Not Built Yet

As an MVP, we've intentionally left out several features to focus on the core bounty platform.

- **Dispute Handling**: Logic for contested submissions.
- **Complex Search**: Integration with Elasticsearch or Algolia for full-text search.
- **Reputation Engine**: Advanced scoring based on completion rates and peer reviews.
- **Real-time Updates**: WebSocket integration for live bounty status changes.
- **GitHub Sync**: Automatic submission creation from PRs.
- **Multi-chain Support**: Support for multiple blockchains.
- **Native Token**: A native token for BountyPort governance and incentives.
- **Mobile App**: A mobile app for contributors and maintainers.

## Roadmap

### Phase 1: MVP Core Features (Current)

- [x] Bounty creation and funding.
- [x] Work submission and approval.
- [x] Payout distribution.
- [x] Basic bounty discovery.
- [x] Contributor profiles and performance metrics.

### Phase 2: Enhanced Features

- [ ] Dispute handling and resolution.
- [ ] Improved search and filtering.
- [ ] Reputation system for contributors and maintainers.
- [ ] Real-time updates for bounty status.

### Phase 3: Community and Ecosystem

- [ ] GitHub sync for submissions.
- [ ] Multi-chain support.
- [ ] Governance and incentive mechanisms.
- [ ] Community-driven bounty creation and funding.
